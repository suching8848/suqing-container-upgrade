# 蘇清的容器升级

<img src="SuQingContainerUpgrade/42/icon.png" alt="蘇清头像图标" width="88" align="right">

**v1.0.0 · Project Zomboid Build 42.21 · 单人模式**

用碎布条、皮革条和针线，逐步强化已有的可穿戴容器。保留原物品与原有功能，使用游戏原生制作分类和快捷制作入口。

已发布 [Steam 创意工坊版本](https://steamcommunity.com/sharedfiles/filedetails/?id=3823988025)，GitHub 同时提供源码与可手动安装的模组文件。本版不包含 EX 档。

## 功能与适配范围

- 明确支持 **168 个完整物品 ID**：原版 84 个、已审计模组 84 个。不同朝向、尺寸、颜色分别计数。
- 五档强化、首次规格还原，以及成功还原后的实付材料返还。
- 适配清单内的前后换位、同 ID 穿戴替换和 8 条原生尺寸转换，保留有效强化记录。
- 浣熊市背包、背带沿用原沙盒和角色特性算法，修正其原有实际容量提示行。
- 专用头像、强化图标、还原图标和封面；没有自建右键菜单、额外等级悬浮区或成功失败弹字。

查看 [168 项支持名单](SuQingContainerUpgrade/最终适配物品名单.txt) 和 [187 项完整分类与限制](SuQingContainerUpgrade/适配名单.csv)。完整分类另含 1 项仅还原和 18 项排除；未知 ID 默认不支持。

兼容范围包含幻想工坊、二维衣橱、背包系统、苏别璃原始装备、They Knew Continued、浣熊市、SafeWayHamlet 和 MFS 中的指定容器。**无需为使用原版容器而安装全部这些模组**，原模组物品仍由各自模组提供。

## 五档规格与成本

表中是每一档单独支付的成本，不是累计成本。容量与减重为该档目标下限，已有更高值会保留。

| 档位 | 名义基础容量 | 减重目标 | 干净碎布条 | 皮革条 | 普通线用量 | 裁缝等级 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Ⅰ | 12 | 90% | 4 | 0 | 2 | 0 |
| Ⅱ | 20 | 93% | 6 | 2 | 4 | 1 |
| Ⅲ | 30 | 95% | 10 | 4 | 6 | 2 |
| Ⅳ | 40 | 97% | 14 | 6 | 8 | 3 |
| Ⅴ | 最高 49 | 99% | 20 | 10 | 10 | 4 |

针保留。普通满卷 `Base.Thread` 有 **20 用量**，表中的“线用量”不是线轴个数。材料 ID 为 `Base.RippedSheets`、`Base.LeatherStrips`、`Base.Thread`；针按原生缝纫针标签识别。

容量和减重同时达到某档时会跳过该档，只支付实际执行的下一档。仅一项较高时，该高值也不会降低。

普通容器Ⅴ档最高为基础容量 49；部分重包为了保留实际自重，使用 `floor(50 - 自重)` 的安全容量上限，满级可能是 **46、47 或 48**。角色特性仍会影响有效容量。原生 50/60 标称容量的指定包只提高减重，不改物理容量；浣熊市两件容器保留较大的沙盒基础值。具体规则以名单为准。

## 安装与使用

Steam 订阅与 Git 手动下载 **二选一**。两种来源使用同一 Mod ID：**`SuQingContainerUpgrade_4221`**，相同 ID 只保留一份安装来源；切换前完全退出游戏，备份存档与旧版文件并移开重复本地副本，停用旧测试版。

### Steam 订阅（推荐）

1. 打开 [蘇清的容器升级创意工坊页面](https://steamcommunity.com/sharedfiles/filedetails/?id=3823988025)，点击 **订阅**。
2. 等待 Steam 完成创意工坊下载，再启动 Build 42.21 游戏。
3. 在游戏模组列表和目标单人存档的模组管理中启用“蘇清的容器升级”。
4. 完全退出并重新启动游戏，使新版 Lua 和资源生效，再进入目标存档。

### Git 手动下载

1. 点击仓库的 **Code → Download ZIP**，解压后将其中的 **`SuQingContainerUpgrade` 文件夹**放入 `%UserProfile%\Zomboid\mods\`。
2. 确认目录形如 `%UserProfile%\Zomboid\mods\SuQingContainerUpgrade\42\mod.info`，并保留同级的 `common` 等目录；不要把整个仓库根目录当成模组文件夹。
3. 在游戏模组列表及目标单人存档中启用“蘇清的容器升级”，然后完全退出并重新启动游戏。手动安装需要自行下载后续更新。

### 开始使用

将目标容器卸下，放入人物主物品栏并清空内部物品。准备材料，在制作菜单的“蘇清”分类中选择当前下一档。使用原版容器无需安装适配表中的全部第三方模组。

**水袋背包、水袋胸挂等储液容器，强化和还原前都必须排空全部液体。** 只移走普通物品不够，剩余少量水或其他液体也会阻止制作。只加强普通物品收纳，不增加储水升数，也不改液体组件。

制作面板的旧档位可能仍显示可选；候选列表或缓存不代表当前这件容器可做该档。同一件只允许下一档，旧档会正常拒绝且不扣料。已排队的动作仍可能耗时，动作结束本身不代表强化成功。

前后换位前，先把目标槽的另一件包卸入主物品栏。目标槽被占用时正常拒绝，不自动挤掉或丢掉另一件包。

## 还原与返料

清空并卸下容器后，使用“还原首次强化前的规格”。这是恢复首次规格，不是逐级降档；还原不加经验。

成功还原返还 **有效支付账本中各类累计实付量的 50%，分别向下取整**。布、皮革按件；普通线按用量，可能返还部分线轴。完整实际支付Ⅰ至Ⅴ共消耗 54 布、22 皮革、30 线用量，对应返还 27 布、11 皮革、15 线用量。

只有真实扣料成功后的支付才记账。跳过档位、免费制作和未实际扣料的操作不产生返料；旧记录没有账本的历史付款不追溯。自 0.2.2 起已有的合法实付账本继续有效，例如旧Ⅳ档之后才支付Ⅴ档，只返这笔Ⅴ档付款的一半。成功还原会清除账本，重复点击不能重复领取。取消制作不按这条 50% 规则结算。

停用模组不会自动还原已保存的物理属性，移除前请先按需还原，并保留容器所属模组。

## 保留原有功能与限制

强化修改原物品实例的受管容量、减重和自身记录，保留原自重、名称、外观、耐久、收藏、穿戴槽、挂点和其他 ModData。

- 原有换弹标签、MFS 自动装弹判定和装填逻辑不改；不会通过提高容量增加每次动画的装弹数量。
- 胸挂的最大物品尺寸、弹带的弹药过滤函数和肩挂枪套最多 2 个手枪弹匣的限制继续生效。
- 前后换位与尺寸转换仅覆盖已核对的精确原生动作；用已强化包作为其他制作配方的消耗材料，不保证新产物继承强化，请先还原。
- 踏行千山、原版粗制皮包和粗制防水布包沿用自己的原生扩容链，不加入收费强化；踏行千山五仅为已有有效记录保留还原。
- 传奇背包 10 色和 Estate 39 的 Miku 背包已达到普通目标，不加入收费强化。非穿戴箱子不在范围内。

## 验证范围

维护者已确认 **v1.0.0 在个人 Build 42.21 单人环境中使用正常**；开发期间完成单人代表项验证及独立离线回归。168 是适配范围，**不是 168 项均已逐件进行游戏内验收**，也不代表全部保存重进、装弹或其他组合场景已经验证。

本版只用于单人。多人和专用服务器未验证，当前前置检查不开放联机强化和还原。详见 [测试说明](docs/TESTING.md)。

## 维护适配名单

唯一适配登记源是 `SuQingContainerUpgrade/compatibility/registry.json`。从仓库根目录运行 Python 3：

```sh
cd SuQingContainerUpgrade
python tools/build_compatibility.py
python tools/build_compatibility.py --check
```

生成器更新运行时白名单、六个配方和人类可读名单；`--check` 只检查生成结果是否一致。修改适配范围应同时审计原物品的容量、限制、原生升级链和换位/尺寸转换。游戏运行不需要 Python。
