# 素材与来源

封面、头像和六枚配方图标由 AI 辅助生成，依据维护者提供并确认的白发、紫瞳、双龙角角色参考统一视觉，再确定性缩放为游戏使用的 PNG。

| 文件 | 用途 |
| --- | --- |
| `SuQingContainerUpgrade/42/icon.png` | 模组列表头像 |
| `SuQingContainerUpgrade/42/poster.png` | 游戏模组详情封面 |
| `SuQingContainerUpgrade/42/media/ui/CategoryIcon/SuQing.png` | Neat Crafting 分类图标 |
| `docs/images/cover.png` | 封面副本，用于仓库说明 |
| `SuQingContainerUpgrade/42/media/textures/Item_SuQingUpgrade1.png` 至 `Item_SuQingUpgrade5.png` | 五档强化配方 |
| `SuQingContainerUpgrade/42/media/textures/Item_SuQingRestore.png` | 还原配方 |

本仓库包含本补丁代码、美术和兼容元数据，不打包原游戏或其他模组的完整代码、模型与纹理。Project Zomboid 及各兼容模组的内容归各自作者，物品仍由原模组提供。

兼容元数据的 `source` 使用 `game/media/...` 和 `workshop/108600/...` 等可移植来源标识；源文件哈希用于记录审计版本，不要求本机采用相同的磁盘目录。

仓库目前未附加开源许可证。
