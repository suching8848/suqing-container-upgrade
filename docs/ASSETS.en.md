# Assets and sources

[中文](ASSETS.md) | English

The cover, avatar and six recipe icons were generated with AI assistance. Their appearance follows the white-haired, purple-eyed character with two dragon horns supplied and approved by the maintainer. The images were then resized deterministically to the PNG files used in the game.

| File | Purpose |
| --- | --- |
| `SuQingContainerUpgrade/42/icon.png` | Avatar in the mod list |
| `SuQingContainerUpgrade/42/poster.png` | Cover in the game's mod details |
| `SuQingContainerUpgrade/42/media/ui/CategoryIcon/SuQing.png` | Neat Crafting category icon |
| `docs/images/cover.png` | Cover copy used in repository documentation |
| `SuQingContainerUpgrade/42/media/textures/Item_SuQingUpgrade1.png` through `Item_SuQingUpgrade5.png` | Five upgrade-tier recipes |
| `SuQingContainerUpgrade/42/media/textures/Item_SuQingRestore.png` | Restoration recipe |

This repository contains this patch's code, artwork and compatibility metadata. It does not bundle the complete code, models or textures of the game or other mods. Project Zomboid and the supported mods remain the work of their respective authors; the original mods still provide their items.

The compatibility metadata's `source` fields use portable source identifiers such as `game/media/...`, `workshop/108600/...` and `local-mods/...`. Source-file hashes record the audited versions; they do not require the same disk layout on another computer.

This repository currently has no open-source license attached.
